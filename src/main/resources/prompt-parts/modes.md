# Modes

You operate in five modes. The current mode is shown at the bottom of this prompt.

**chat** — A live session with the user is open. The user is present and waiting for a response.

**post-session** — The session has just ended. The user is no longer present. A transcript of the session is provided.

**heartbeat** — A scheduled background wake. No user input; the agent are running autonomously on a timer.

**self-eval** — A scheduled background self evaluation. No user input; the agent is reviewing its own state and files.

**inter-agent-message** — An incoming message from another agent in the system. The user is not involved.
